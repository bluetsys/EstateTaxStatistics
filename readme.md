# 상속세·사망자수 통합 심층 분석 리포트

## 1. 개요

국세청의 **상속세 신고·결정 통계**와 국가데이터처의 **사망자수·조사망률·기대수명 통계**를 연도 단위로 비교하는 데이터 내장형 HTML 리포트입니다. 재산 규모·과세표준 분포, 1인당 평균, 장기 증감 추세, 고액 상속 집중도, 사망자 대비 상속세 통계 비율을 살펴볼 수 있습니다.

- 메인 파일: `상속세_사망자수_통합_심층분석_2006-2025.html`
- 분석 기간: 상속세 신고 **2006~2025년**, 상속세 결정 **2007~2025년**
- 사망 관련 자료: 제공된 CSV의 연도별 값 사용. **2025년 기대수명은 원자료에 없어 표시하지 않습니다.**
- 데이터 갱신 기준: 제공된 **2026년 10월 20일** 다운로드 CSV

## 2. 실행 방법

1. HTML 파일을 다운로드합니다.
2. Chrome, Edge, Firefox 등 웹 브라우저에서 파일을 엽니다.
3. 상단의 **연도 선택**, **분석 유형**, 기타 선택 항목을 변경해 그래프·표·해설을 확인합니다.

데이터와 시각화 코드가 HTML에 내장되어 있으므로 별도의 웹 서버나 CSV 파일은 필요하지 않습니다. KOSIS **출처 링크를 열 때만 인터넷 연결**이 필요합니다.

## 3. 주요 분석 내용

| 영역 | 확인할 수 있는 내용 |
|---|---|
| 핵심 변화 | 전년 대비 인원·금액 변화 및 자동 해설 |
| 증가 원인 분해 | 총액 변화를 피상속인수 변화와 1인당 평균 변화로 구분 |
| 고액 상속 집중도 | 특정 재산 구간의 인원 비중과 재산 점유율 |
| 연도별 구조 변화 | 증가율, 장기 성장, 최고·최저 연도 |
| 신고·결정 비교 | 같은 연도 두 통계의 인원·재산가액·과세표준 비교 |
| 1인당 평균 | 총상속재산가액 등 ÷ 피상속인수 |
| 사망 관련 비교 | 사망자수 대비 신고·결정 피상속인수 비율, 조사망률 및 기대수명 추세 |
| 상세 데이터 | 구간별 원자료 값 조회 및 제공되는 CSV 내보내기 |

## 4. 계산식·단위

- **1인당 평균 금액** = 해당 통계 금액 합계 ÷ 피상속인수. 원자료 금액이 `백만원` 단위라면 **억 원**으로 표시할 때 100으로 나눕니다.
- **사망자 대비 신고 비율(%)** = 해당 연도 신고 피상속인수 ÷ 해당 연도 사망자수 × 100.
- **사망자 대비 결정 비율(%)** = 해당 연도 결정 피상속인수 ÷ 해당 연도 사망자수 × 100.
- **전년 대비 증감률(%)** = (올해 값 ÷ 전년 값 − 1) × 100. 전년 값이 없거나 0인 경우 계산할 수 없습니다.
- **구간 점유율(%)** = 구간 합계 ÷ 전체 합계 × 100 (비교 가능한 같은 지표 기준).
- **조사망률(‰)** = 인구 1,000명당 사망자수로, 사망자수 자체와 다른 지표입니다.

## 5. 해석 시 주의사항

1. 이 리포트의 **1인당 평균은 피상속인(사망한 재산 소유자) 1명당 통계 평균**입니다. 개별 상속인 한 사람이 물려받은 금액이나 실수령액이 아닙니다.
2. 신고·결정 통계는 **같은 연도의 동일 사건을 1:1 매칭한 자료가 아닙니다.** 두 수치의 차이를 세무조사 결과나 추징액으로 해석해서는 안 됩니다.
3. **사망자 대비 신고·결정 비율은 동년도의 서로 다른 집계 수치를 나눈 참고 지표**입니다. 실제 사망자 중 상속세 신고 의무자의 비중이나 같은 사망 코호트의 확정 비율이 아닙니다. 신고·결정의 시차가 존재합니다.
4. **총상속재산가액, 과세표준, 산출세액, 총결정세액, 자진납부할세액**은 서로 다른 개념입니다. 특히 신고와 결정의 세액 항목을 동일한 세금으로 직접 비교하면 안 됩니다.
5. 과거 연도의 통계 항목 정의·제공 범위가 다를 수 있습니다. 원자료의 `-`, 공란 등은 임의로 0으로 보충하지 않아야 합니다.
6. 상속세 증가와 사망자수·기대수명 변화 사이의 동행은 **인과관계를 증명하지 않습니다.** 세제 변경, 자산가격, 신고 시차 등을 별도로 검토해야 합니다.
7. **2025년 기대수명은 제공된 원자료에서 미제공**이므로 추정하거나 임의로 대체하지 않았습니다.

## 7. 데이터 업데이트

현재 HTML은 다운로드 시점의 데이터를 **내장한 정적 리포트**입니다. KOSIS 통계가 수정되거나 다음 연도 수치가 발표되어도 자동으로 동기화되지는 않습니다. 새로운 데이터 반영을 위해서는 CSV를 새로 내려받고 HTML의 내장 데이터를 갱신해야 합니다.

### CSV에서 `data.js` 다시 생성

세 원본 CSV와 `convert.js`를 같은 폴더에 둔 뒤 Node.js로 실행합니다. CSV 파일명은 각각 `6.1.2_`, `6.2.2_`, `사망자수__조사망률__기대수명_`으로 시작해야 합니다.

```bash
node convert.js
```

변환기는 상속세 신고·결정 자료를 `DATA`, 사망 관련 자료를 `MORTALITY`로 만들어 `data.js`를 덮어씁니다. 페이지가 `data.js`를 직접 읽으므로 변환 뒤 브라우저를 새로고침하면 됩니다.
